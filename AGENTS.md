# Проект:
Цель проекта, обработка фото пользователя и возврат ему ссылки на вино из фото.
Подробнее в `README.md`

## СТЕК:
- FastAPI, Qdrant
- PostgreSQL, SQLAlchemy

## Архитектура: 
- Onion Architecture
- Routers / Services / Repositories

## Структура проекта: 
- `src/`
  - `main.py` точка входа в проект
  - `api/v1/endpoints/`
  - `repositories/`
  - `services/`
  - `schemas/`
  - `utils/`

## Этапы работы
* Придерживайся принципа `Test-Driven Development`

- Ознакомление с кодом
- Построение плана
- Написание и запуск тестов `pytest` (Тесты должны покрывать всю бизнес-логику)
- Написание кода 
- Запуск тестов
- (Если тесты прошли) Рефакторинг (если же нет то возвращаемся к написанию кода)

## Теоретический подход к решению задачи:
- Обработать базу изображений `data/images/` для связи со ссылками `data/embeddings/wine_links.json`
  - Необходимо векторизовать эти данные и загрузить их в `qdrant` в соответствующие коллекции.
    - Список коллекций: `siglip2-vectors`, `ocr-data-vectors` (для лучшего понимания ознакомится с `src/services/retrieval.py`)

- Разработать endpoint поиска в базе нужного вина:
  - Наработки в `src/api/v1/endpoints`
