USER (пользователь делает фото вина и отправляет в сервис) ->
SERVER (сервис находит вино и возвращает ссылку пользователю) ->

Пример ссылки: `https://vino-svoe.ru/wines/sosedi-aligote-shardone-2025`

### Принцип работы сервиса: 
- Векторизация фото
- Транскрибация фото (photo-to-text) + векторизация транскрипции

- Поиск 2 векторов (фото и полученный текст) в векторной базе данных

- Возврат пользователю ссылки на нужное вино которое набрало больший score
